# Projeto SPA em Vanilla JavaScript

Aplicação Single Page Application (SPA) desenvolvida com modularização nativa do ES6, manipulação do DOM e visualização de dados dinâmica.

## 🚀 Tecnologias Utilizadas
- HTML5 & CSS3
- JavaScript ES6 (Modules, History API, Async DOM manipulation)
- [Chart.js](https://www.chartjs.org/) (via CDN para dashboards)
- Web Storage API (`localStorage`)

## 📁 Estrutura de Módulos
- `js/modules/router.js`: Roteamento do lado do cliente via History API.
- `js/modules/storage.js`: Abstração para persistência no `localStorage`.
- `js/modules/validation.js`: Funções puras para validação de entradas.
- `js/main.js`: Orquestrador principal da aplicação.
